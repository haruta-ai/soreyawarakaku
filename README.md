# それ、やわらかく。

言いにくい本音を、相手とトーンに合う大人の言い方へ変える、軽量なPWAです。

## 公開方法（GitHub Pages）

1. ZIPを展開し、中のファイルをGitHubリポジトリの最上位へ置きます。
2. GitHubの「Settings」→「Pages」を開きます。
3. 「Deploy from a branch」を選び、公開するブランチと `/ (root)` を指定します。
4. 表示された公開URLをSafariで開きます。

ビルド、npm、外部API、秘密キーは不要です。github.devでは各ファイルをそのまま編集できます。iPhoneからのGit操作にはWorking Copyを利用できます。

## iPhoneでの確認

- Safariで公開URLを開き、カテゴリ→本音→相手→トーン→3案の順で操作する
- コピー、お気に入り、履歴、検索を確認する
- 共有ボタン→「ホーム画面に追加」から起動する
- 一度読み込んだ後に機内モードへ切り替え、ホーム画面のアイコンから再起動する
- 画面の回転、文字サイズ拡大、「視差効果を減らす」設定でも操作する

## データの追加

言い換えデータは `data.js` に集約されています。カテゴリと本音の追加は、このファイルだけで完結します。アプリ本体の画面制御は `app.js`、見た目は `styles.css` です。

更新を確実に反映するときは、`sw.js` の `CACHE_NAME`（例：`yawarakaku-v1`）の末尾番号を上げてください。

## プライバシー

通信、ログイン、外部APIは使いません。お気に入り・履歴・初回説明の確認状態はブラウザのlocalStorageにだけ保存します。音声の録音・送信機能はありません。
