# それ、やわらかく

本音を選び、相手とトーンを指定すると、端末内のデータから自然な言い換えを3案提示する静的PWAです。外部API・アカウント・従量課金はありません。

## ローカル確認

このフォルダで静的HTTPサーバーを起動し、表示されたURLをSafariで開いてください。Service WorkerはHTTP(S)環境で動作します。

## GitHub Pages

このフォルダの中身をリポジトリのルートへ配置し、GitHubの Settings → Pages → Deploy from a branch で対象ブランチの `/ (root)` を選択します。サブパス公開に対応する相対URLを使用しています。
